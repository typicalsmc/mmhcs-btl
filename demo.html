Quan sát một chuỗi tin cậy

Nhấn “Chạy demo thực tế”. Controller tạo PKI, khởi động Nginx/DNS và chạy client Docker mới cho mỗi kết nối.

Giao thức: TLS 1.3Kho tin cậy: riêng trong lab
$ python3 demo.py --self-test Chưa có kết quả chạy. Không cài CA vào hệ điều hành.

Đây là kết nối của victim Docker, không phải trình duyệt bị chuyển hướng. Chính sách trust/thu hồi của trình duyệt không phải chính sách victim. Không đổi DNS hoặc kho CA của host.

Lệnh terminal tương đương
python3 demo.py --action setup
python3 demo.py --action attack --run-id ID
python3 demo.py --action probe --run-id ID
docker compose --env-file runs/ID/compose.env -p pki-lab-ID run --rm --no-deps ca bash /lab/revoke-cert.sh
python3 demo.py --action probe --run-id ID --check-crl
python3 demo.py --action recover --run-id ID
python3 demo.py --action down --run-id ID

Thay mọi ID bằng run_id từ setup. Bash chạy trong container Linux.
